# Theme Implementation

Реализация системы переключения тем (светлая/темная/следовать системной) в приложении CakeCost.

## Компоненты системы

### 1. Утилиты темы (`src/utils/theme.ts`)

**Функции:**
- `applyTheme(themeMode)` - Применяет тему через Quasar Dark API
- `getSystemThemePreference()` - Определяет текущую системную тему
- `watchSystemTheme(callback)` - Следит за изменениями системной темы

**Поддерживаемые режимы:**
- `light` - Светлая тема
- `dark` - Темная тема
- `auto` - Следовать системной теме (использует `prefers-color-scheme`)

### 2. Инициализация темы (`src/boot/theme.ts`)

**Функция `initializeTheme()`:**
- Загружает сохраненную тему из настроек
- Применяет тему при запуске приложения
- Устанавливает наблюдатель за изменениями темы в store
- В режиме `auto` следит за изменениями системной темы

### 3. Store настроек (`src/stores/settings.ts`)

**Существующий функционал:**
- `theme` - Текущая тема (ref)
- `isDarkMode` - Вычисляемое свойство, учитывающее режим `auto`
- `saveTheme(newTheme)` - Сохранение темы в SQLite
- `loadSettings()` - Загрузка темы из базы данных

### 4. Интеграция в приложение (`src/main.ts`)

**Последовательность инициализации:**
1. Создание Vue приложения
2. Подключение Quasar, Pinia, i18n
3. Монтирование приложения
4. Загрузка настроек из SQLite
5. Инициализация системы тем

### 5. UI переключателя (`src/pages/SettingsPage.vue`)

**Функционал:**
- Переключатель с тремя опциями (QBtnToggle)
- Немедленное применение темы при изменении
- Сохранение выбора в базу данных

## Как это работает

### Режим "Светлая" (light)
```typescript
settingsStore.saveTheme('light')
// → Dark.set(false)
// → Сохранение в SQLite: theme = 'light'
```

### Режим "Темная" (dark)
```typescript
settingsStore.saveTheme('dark')
// → Dark.set(true)
// → Сохранение в SQLite: theme = 'dark'
```

### Режим "Следовать системной" (auto)
```typescript
settingsStore.saveTheme('auto')
// → Dark.set('auto')
// → Quasar автоматически следует за системной темой
// → Устанавливается наблюдатель за изменениями системной темы
// → Сохранение в SQLite: theme = 'auto'
```

## База данных

Тема сохраняется в таблице `settings`:

```sql
UPDATE settings
SET theme = ?, updated_at = strftime("%s", "now")
WHERE id = 1
```

**Возможные значения:** `'light'`, `'dark'`, `'auto'`

## Особенности реализации

### 1. Автоматическое следование системной теме
В режиме `auto` используется `window.matchMedia('(prefers-color-scheme: dark)')` для определения системной темы и отслеживания её изменений.

### 2. Совместимость с браузерами
Поддерживаются как современные браузеры (addEventListener), так и старые (addListener).

### 3. Реактивность
Изменения темы в store автоматически применяются через Vue watcher без перезагрузки приложения.

### 4. Персистентность
Выбранная тема сохраняется в SQLite и восстанавливается при следующем запуске приложения.
